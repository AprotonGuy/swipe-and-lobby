# Swipe & Lobby — online zetten (zelfde setup als Europedia)

Deze map is de complete game als gewone website. Hij werkt op pc én telefoon, en is op de telefoon te installeren als app ("Zet op beginscherm").

## Stappen
1. **Codeberg:** maak een nieuwe repository, bijvoorbeeld `swipe-and-lobby`.
2. **Uploaden:** zet alle bestanden uit deze map erin, met dezelfde mappen (ook `art/`). Op de Codeberg-website kan dat via *Add file → Upload file*.
3. **statichost.eu:** maak een nieuwe site en koppel die aan de Codeberg-repository.
   - Er is geen build-stap nodig: de map zelf is de website.
4. **Klaar:** statichost geeft je een link. Die werkt op pc en telefoon.
   - Op de telefoon: open de link → menu → *Zet op beginscherm*.

## Goed om te weten
- **Opslag:** voortgang, de Secret list en het spook worden per apparaat in de browser bewaard.
- **Regiekamer-teksten:** de teksten uit de Regiekamer zitten er nu in. Pas je later iets aan in de Regiekamer, laat Claude dan een nieuwe export maken en upload de nieuwe bestanden.
- **Lettertypes:** de lettertypes komen van Google Fonts.
